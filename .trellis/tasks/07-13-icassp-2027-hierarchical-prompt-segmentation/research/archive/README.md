# Superseded Group-Server Records

These records document measurements and constraints from the former group
server (`j3s2`, dual RTX 2080 Ti). They are retained only for provenance.

They are not valid training, profiling, checkpoint-selection, or reproducibility
evidence for the ICASSP 2027 experiments. All future experiments use the
single RTX 4090D AutoDL environment defined in the parent task PRD.
